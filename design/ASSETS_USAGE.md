# Where to place figures and how to credit them

| Page | Figure / interactive evidence | Actual source or suggested generation | Rights status |
|---|---|---|---|
| Home/LAB4 intro | Phage electron micrograph + plaque photo collage | Wikimedia Commons https://commons.wikimedia.org/wiki/File:Bacteriophages_at_work_colour.jpg | CC BY-SA 3.0. Attribute Emily Brown plus original image contributors. |
| LAB4 M1 | Laboratory plaque photograph | Wikimedia image above is generic illustration, **not a PhageHostLearn observation** | Put caption `Illustration; not part of the analyzed dataset`. |
| LAB4 M2 | Host-range heatmap | **Generate from selected, verified PhageHostLearn rows** (R / JS) | Original scientific data; verify Zenodo reuse rights. Color unknown pairs separately. |
| LAB4 M3 | Small phage genome map | **Generate from a verified GenBank/FASTA** using CGView.js | Cite the particular accession and annotation version; no invented feature IDs. |
| LAB4 M4 | CRISPR immunity overview | https://commons.wikimedia.org/wiki/File:CRISPR_defence_system_diagram.svg | CC BY 4.0, Domdomegg. |
| LAB4 M4 | PA14/DMS3 experimental comparison | Derive an original classroom chart from documented qualitative findings or author-provided raw numeric data | Do not copy protected article panels or invent numeric experimental results. |
| LAB3 M1 | FastQC and QUAST reports | Generate by running actual tools once on a frozen selected read set | Precomputed, label with exact versions and run parameters. |
| LAB3 M2 | Bacterial genomic context | JBrowse 2 from frozen annotated genomes and corresponding GFF | Cite isolate accession(s). |
| LAB3 M3 | Virulence/AMR results | Generate from annotated selected isolates using a documented database version | Negative results are acceptable; do not force a dramatic gene. |
| LAB3 M4 | SNP tree and metadata | Freeze the relevant NCBI PDS cluster version; optional live NCBI tree link | State time of download. Genome relatedness alone does not prove transmission. |
| LAB1 | QC figures and read retention | Existing AmpWrap course files; use genuine AmpWrap logs/reports | Preserve real sample identity. |
| LAB2 | SEA4BLUE map and PCoA | Existing course project output | Check originally included image credits. |

**Additional optional overview graph:** https://commons.wikimedia.org/wiki/File:Bacteriophage_plaquing_host_range_values_by_bacteriophage_families.svg (CC0, Ivan Pchelin). It is a literature synthesis and should NOT be shown as the lab's own host-range matrix.
